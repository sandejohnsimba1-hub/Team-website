# CodeCrafters — Team Website (CSC 216, Lab 2)

A responsive, multi-page team portfolio website built with semantic HTML5, modern CSS3, and vanilla JavaScript.

## Features
- **Responsive Layout:** Mobile-first navigation menu and flexible card grids using CSS Flexbox and Grid.
- **Dark Mode:** Persistent light/dark theme toggle powered by `localStorage`.
- **Dynamic Project Filtering:** Interactive category filtering (`All`, `HTML`, `CSS`, `JS`, `Git`) rendered via JavaScript.
- **Form Validation:** Client-side validation with live character counting and accessible error states on the Contact page.

## Pages
- `index.html` — Home page with team introduction and member profile cards.
- `projects.html` — Filterable showcase of team and individual projects.
- `contact.html` — Interactive contact form with real-time validation.
